# Ashgrove Integration Catalogue (fictional)

## CRM connectors

Generally available connectors for Microsoft Dynamics 365 Customer Service and Salesforce Service Cloud, including Salesforce Health Cloud objects, through supported vendor APIs.

## Contact-centre connectors

Generally available connectors for Genesys Cloud CX and Amazon Connect, covering transcripts, interaction context and agent hand-off. A Five9 connector is on the roadmap for H2 2027.

## Data platform integration

Batch export (hourly or daily) to Microsoft Fabric, Snowflake and Databricks is generally available. Real-time event streaming is on the roadmap for Q2 2027; today a limited set of events is available by webhook.

## APIs

Documented REST APIs and webhooks with OAuth 2.0, versioned and backward compatible for 12 months.

# Design reference

These four HTML files are **visual references only**: the animated background, logo, colours, type and motion that the web app should match. Open them directly in a browser (`start design\prototype.html`).

| File | Reference for |
|---|---|
| `prototype.html` | Landing page: animated background, logo, section reveals |
| `dashboard.html` | Dashboard layout, stat tiles, queue, Mubit panel |
| `call-console.html` | Live call view: transcript, chips, side panels |
| `iphone-call.html` | Phone mock-up styling |

**Their content predates the final architecture** (they show an AI agent talking to the customer). The product is now call QA: a bank colleague handles the call and Redress scores it. See the root README.

**Theme tokens** (also in `web/app/globals.css`): background `#050906`, lime `#7CFF4F`, text `#eef3ec`, muted `#8b968d`, amber `#ffb25e`, red `#ff7a6b`; fonts Inter Tight and JetBrains Mono.
